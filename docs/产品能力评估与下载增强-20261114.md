# SAB 产品能力评估与下载增强

时间：2026-11-14；作者：lq。

本次目标：围绕轻量日常浏览补齐基础可用性，下载按用户要求优先交付。结论来自当前源码、组件交互测试、Rust 测试与隔离 macOS 原生 WebView 验收；未完成整套界面截图审查、Windows 真机验收或长时间资源基准，不能据此宣称性能领先其他浏览器。

## 产品现状与取舍

已有多标签、原生网页视图、地址/搜索识别、历史补全、主页最近访问、收藏分类管理/导入/规则整理和浅深色外观。使用系统 WebView、Vue 和本地 SQLite，适合保持小体积和本地优先。产品下一步应优先让打开网页、下载文件、找回页面和管理数据形成完整流程。

## 本次已完成

| 用户流程 | 修改前 | 本次行为 |
| --- | --- | --- |
| 网页下载 | 原生下载全部拒绝 | 系统保存面板选择文件名和目录；沿用原生网页登录态、附件响应和 Blob 下载 |
| 查看下载 | 无入口和记录 | 顶栏下载入口、活动任务数、下载面板；开始/完成/失败事件刷新，本地记录跨启动保留 |

| 启动 | 固定等待至少 620 毫秒 | 本地初始化后立即交互，取消人为最低等待 |
| 网页历史更新 | 标题变化也被当作加载完成，每次写历史后重读设置/分类/最近记录 | 标题事件与完成事件分离，按标签合并临近事件；只刷新历史与最近访问 |
| 搜索输入 | 每个按键直接发数据库查询 | 地址、收藏浮层、收藏页面和历史页面合并 180 毫秒内的连续输入；切换条件/离开页面取消排队查询并作废过期响应 |
| 转到内置页面 | 原网页隐藏后继续常驻 | 同一标签转到主页等内置页时释放原生网页视图 |
| 多标签内存控制 | 只有关闭标签 | 菜单显示实际网页视图数；手动确认休眠后台网页，保留标题网址，选择时重新加载 |
| 网页操作 | 仅刷新 | 加载中可停止；菜单支持 50%–200% 原生缩放，按标签保留比例 |
| 故障与开发保障 | 错误属于全局状态，App 跳过类型检查 | 错误跟随标签、提供重新尝试；恢复 App 的 TypeScript 检查 |
| 网页焦点下快捷键 | 外壳键盘事件无法覆盖原生网页 | 接入应用原生菜单，统一地址栏、新建/关闭/恢复标签、刷新、切换、下载、收藏、缩放和退出动作；保留原生复制粘贴等编辑菜单 |
| 重新启动 | 仅主页或指定启动页 | 默认保存网址、标题、当前标签、缩放和最近关闭的20个标签；指定启动页优先；恢复只创建当前网页，后台标签按需加载 |
| 关闭会话保存 | 无对应偏好 | 关闭并保存后清除会话，后端拒绝晚到的自动保存；快照不含正文、表单、错误或加载状态 |
| 加载异常 | 命令报错才有反馈 | 设备离线和等待超过30秒显示独立提示；可重试、继续等待、回主页；恢复网络不会自动重发请求，真实完成后清除提示 |

休眠会丢失未提交表单、滚动位置及网页内的导航记录，因此采用用户主动确认，不自动按时间休眠。显示的是网页视图数量，不将其伪装成内存占用数值。

## 下载的明确边界

- 当前 Tauri 原生下载事件只提供请求/结束，不提供统一的暂停、单任务取消、断点续传或总大小接口。本次曾验证“关闭来源 WebView”方案，发现不能可靠终止 macOS 系统下载，已撤回相关实现，没有交付无效取消按钮。
- 支持取消系统保存对话框；已开始的下载可以等待完成，或确认退出浏览器并在下次启动重新下载。
- 同来源同 URL 的并发下载会被合并为已有任务提示，以避免 macOS 完成事件没有文件路径时误关联；最多同时 10 个任务。
- 原生引擎在部分平台先缓冲后落盘，接收字节可能暂时为零，完成事件和最终内容校验才是成功依据。
- HTTP 重试会重新请求链接，不重放原来的 POST 请求；临时签名过期、需要表单生成的导出文件应回来源网站重新生成。
- 最终提交失败的完整临时文件保留用于找回；退出中断留下的部分文件不会当作完成文件打开，也不承诺续传。
- 系统保存框的人工交互、默认应用打开/目录定位、Windows 实际下载以及大文件持续运行仍需设备验收。

## 验证记录

- `pnpm verify`：类型检查、前端组件/域逻辑测试、生产构建和 Rust 测试。第二轮累计前端21项；Rust16项，均通过。
- 下载组件测试覆盖完成文件只按记录 ID 打开/定位、活动任务不提供打开动作、活动进度不伪造百分比、仅活动任务时不允许清记录、失败重试和清理事件。
- Rust 新增测试覆盖原文件保全、不覆盖提交、明确覆盖后的提交、临时文件缺失、重启中断和清记录不删文件/活动任务。
- `cargo run --manifest-path src-tauri/Cargo.toml --example download_smoke --offline`：macOS 隔离原生引擎运行；本机 HTTP 服务、临时目录和独立 SQLite，不接触用户数据。保存框使用测试替身。
- 原生结果：普通附件 13 B、Cookie 认证附件 21 B、Blob 文件 12 B，均完成且字节一致；断流附件记录失败，不存在目标完成文件。此测试不等于系统文件选择器、文件打开或 Windows 的人工验收。
- `workspace_smoke` 使用真实生产前端、原生子WebView、受限IPC和独立数据库：验证只创建一个恢复网页、地址栏焦点、新建/关闭/恢复及切换标签、离线提示、继续等待不重发请求、下载面板和退出前保存。快捷键通过原生事件通道注入，未模拟物理键盘；离线通过浏览器事件注入，没有更改设备网络。
- 前端新增测试覆盖快照状态剥离、200/20项限制与当前页保留、Unicode标题限制、后台延迟恢复、保存串行与失败恢复、超时取消/重新计时、组合键映射和真实完成清除错误。Rust新增验证会话跨数据库重开、关闭恢复清理并拒绝晚写、不合法快照不覆盖旧记录与菜单动作白名单。
- 生产前端约176 KB JavaScript、gzip约60 KB；这是构建体积，不是安装包体积或浏览进程内存。未采集足以比较其他浏览器的运行性能数据。

## 使用与验收

启动开发版：`pnpm tauri:dev`。在网页点击下载并选保存位置，顶栏“下载管理”可反复打开；完成后尝试打开文件/目录，失败后重试。验证同名文件覆盖、中文名、大文件和网站表单导出。再打开多个网页，通过菜单休眠后台标签，检查再次选择能恢复网址。

本次修改落在源码和构建输出中；没有替换已安装浏览器、发布版本或推送 Git。
