# 网页视图调度优化

时间：2026-11-16；作者：lq。

当前版本还支持 Chrome 密码 CSV 导入、系统凭据库保存及网站内手动填表；实现和边界见[密码迁移说明](Chrome密码导入与手动填表-20261116.md)。

## 改动

- 原生宿主记录唯一可见网页。打开网页、切换标签和显示浮层时只隐藏之前的可见网页，取消对所有后台网页逐个隐藏的操作。
- 当前网页内导航及重复激活不再先隐藏再显示，减少不必要的显示切换。
- 前端跳过队列中已被后续视图同步替代的请求，快速连续切换时读取最终活动标签。
- 内置页面和普通网页默认滚动条改为 10px 透明轨道、圆角滑块，支持浅/深色和高对比模式；保留网站自己的滚动条样式优先级，不建立持续滚动监听。
- 保留已有的后台网页、会话、登录态和下载保护规则。

## 验证

- `pnpm verify` 通过：31 项前端测试、20 项 Rust 测试、类型检查和前端生产构建。
- 隔离原生工作区测试通过：新增连续切换 30 次、重复激活 8 次，以及 Chrome 密码 CSV 预览/导入/重复跳过/删除；网页视图仍为两个、页面请求仍为两次；会话恢复、离线继续等待、下载面板、系统链接及退出保存正常。
- 隔离原生下载测试通过：普通文件、携带 Cookie 的文件、Blob 下载及中断失败场景。
- macOS 钥匙串独立读写与清理测试通过；Playwright 检查填表来源校验、注册表单保护、不提交行为及浅/深/窄屏滚动条。

本次验证确认减少了 SAB 自身的视图操作，并未测量真实互联网网站的首屏耗时或承诺加速比例。macOS 使用系统 WKWebView；网络、网站响应和页面脚本的影响需要结合具体慢网页继续测量。Windows 尚未进行本机原生验收。
