## 版本定位

本版本为供小范围 macOS 体验的预览版，目标是验证日常浏览、收藏整理和下载闭环。它不是 Chrome/Edge 替代品，也不承诺不同操作系统和所有网页的一致兼容性。网页引擎使用操作系统提供的 WebView。

## 已交付

- 多标签、搜索主页、地址栏历史建议、浏览历史和收藏导入/整理。
- 原生附件和 Blob 下载、保存位置、活动记录、失败重试、完成文件打开和目录定位。
- 原生浏览器快捷键、标签恢复、低资源按需创建和后台标签手动休眠。
- 本地保存偏好、历史、收藏、下载记录与可选标签会话；退出时保存最新会话。
- 对下载能力如实限制：不提供暂停、单任务取消或断点续传；下载中的来源标签会受保护。

## 构建与验证

- 应用版本：`0.1.0`；构建号：`2026111401`。
- 支持本机首发构建目标：Apple Silicon macOS 12+；当前源码也配置 Windows NSIS，但没有 Windows 构建和设备验收。
- `pnpm verify`：TypeScript、前端 21 项、生产构建和 Rust 17 项通过。
- 隔离 macOS 原生工作区验收：恢复多个标签但只创建活动网页、地址栏聚焦、标签操作、断网提示、继续等待不重发、下载面板和退出前写入最后快照。
- 隔离 macOS 下载验收：普通附件、登录态附件、Blob 内容正确；断流任务落失败记录且不生成伪完成文件。
- 以上验收通过测试窗口和临时数据库，不代表在其他系统、真实网站、长时间负载下全部接受。

## 发布阻塞与限制

当前环境没有 Apple Developer ID 证书、公证凭据或 updater 签名私钥。本机只可生成未公证、未验证的测试安装包，系统可能阻止从网络安装。不可把它宣传为已签名、已公证或公开分发版本。拿到发行者证书后，应重新签名、公证、staple，并在干净 Mac 安装验收。

首版不支持默认浏览器注册、自动更新、隐私窗口、密码管理、账号同步、站点权限管理、下载暂停/取消/续传。网络接口不能精确提供 DNS/TLS 失败原因，当前提示只区分设备离线和等待超时。Windows WebView2、键盘快捷键、NSIS 安装器均未验收。

发布前应对实际签名的 DMG 执行 `spctl --assess --type open --context context:primary-signature --verbose=4`、挂载安装，并在 macOS 12+ 新用户账户验证收藏、下载、更新数据库和退出恢复；Windows 包另在 Windows 10/11 与干净 WebView2 环境构建验收。公开发布时附带 SHA-256、版本说明、隐私说明、支持渠道和回滚方案。
